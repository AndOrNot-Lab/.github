# AndOrNot Lab

我们探索 AI 与自动化的实际应用，将想法打磨成可靠、可复用的工具。

We explore practical applications of AI and automation, turning ideas into reliable, reusable tools.

## 我们关注 / What we build

- **AI 原生工具 / AI-native tools**：面向信息整理、内容生产与智能工作流。
- **自动化基础设施 / Automation infrastructure**：连接零散流程，减少重复操作。
- **开发者工具 / Developer tools**：将实验沉淀为可复现、可维护的工程能力。

部分项目仍在内部孵化，成熟后将陆续开放。欢迎关注我们的[公开项目](https://github.com/orgs/AndOrNot-Lab/repositories)。

Some projects are still being incubated internally and will be open-sourced as they mature. Follow our [public repositories](https://github.com/orgs/AndOrNot-Lab/repositories) for updates.
