## The lab logic

<table>
  <tr>
    <td width="50%" valign="top">
      <img src="./assets/card-and.svg" width="100%" alt="AND - Connect" />
      <h3>连接 / Connect</h3>
      <p>连接信息、模型与工作流，让分散的能力组成真正可用的系统。</p>
      <sub>Join information, models, and workflows into systems people can actually use.</sub>
    </td>
    <td width="50%" valign="top">
      <img src="./assets/card-or.svg" width="100%" alt="OR - Explore" />
      <h3>选择 / Explore</h3>
      <p>保留不同路径，用实验和真实反馈找到更好的答案。</p>
      <sub>Keep multiple paths open, then let experiments and real feedback decide.</sub>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <img src="./assets/card-not.svg" width="100%" alt="NOT - Refine" />
      <h3>删减 / Refine</h3>
      <p>主动删除噪声、脆弱流程和无意义的复杂度。</p>
      <sub>Remove noise, brittle processes, and complexity that has not earned its place.</sub>
    </td>
    <td width="50%" valign="top">
      <a href="https://github.com/orgs/AndOrNot-Lab/repositories">
        <img src="./assets/card-open.svg" width="100%" alt="Open signal - explore public repositories" />
      </a>
      <h3>开放 / Open</h3>
      <p>项目先在内部孵化；当它足够清晰、可靠且可复用时，再走向公开。</p>
      <sub>Projects incubate privately, then open when they are clear, reliable, and reusable.</sub>
    </td>
  </tr>
</table>

## Lab protocol

> **Useful before novel. Reliable before impressive. Open when ready.**  
> 先解决真实问题，再追求新奇；先做到可靠，再追求惊艳；准备好以后，再开放。
